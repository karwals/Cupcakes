Cupcakes
This is a cupcakes website for my mom to sell cupcake once a week.


It is hosted on https://cupcakes-wellington.netlify.app


What it does

Allow the user to select which cupcakes they want and then they can fill in a form and with there other detail.

How it works
From the admin page which can only be accessed with a password you can change the weekly cupcake and the price and the description 

Deployment
It is hosted on netlify as it is free and easy to use
